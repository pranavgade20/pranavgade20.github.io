Privacy Policy

This privacy policy covers gsuite-mcp, an open-source Model Context Protocol (MCP) server that lets a user's local AI client (e.g. Claude Code) access their own Gmail and Google Calendar. It is published and maintained by Pranav Gade.

Last updated: 2026-05-30.

What gsuite-mcp is

gsuite-mcp runs entirely on the user's own machine. It is a local process launched by the user's MCP client over stdio. It has no server-side component, no hosted backend, and no telemetry. There is no "gsuite-mcp service" that receives or stores user data.

What data is accessed

When the user authorizes the app, gsuite-mcp obtains an OAuth 2.0 access token and refresh token for the Google account the user selects. With those tokens it can call the Gmail API and the Google Calendar API on the user's behalf, scoped to:

  • https://www.googleapis.com/auth/gmail.modify — read, draft, label, and (when the user explicitly enables it via the GMAIL_ENABLE_SEND environment variable) send mail on the user's behalf.
  • https://www.googleapis.com/auth/calendar — read and modify the user's calendars and events.

Data is fetched from Google only in response to a tool call initiated by the user (directly or via their AI client). Examples of data that may transit through the local process: message metadata, message bodies, attachments, label lists, calendar events, attendee lists.

How data is used

Data fetched from Google is returned to the user's MCP client (the program that launched gsuite-mcp) over the local stdio pipe and is not used for any other purpose. gsuite-mcp does not transmit user data to any third party, does not store user content beyond the lifetime of the request, and does not use user data for advertising, analytics, model training, or any purpose unrelated to providing the user-facing features they invoked.

Use of information received from Google APIs adheres to Google API Services User Data Policy, including the Limited Use requirements.

Where data is stored

The following files are written to the user's machine under ~/.config/gmail-mcp/ (or the directory pointed to by GMAIL_MCP_CONFIG_DIR), with file mode 0600:

  • token.json — the OAuth access token and refresh token returned by Google.
  • oauth-client.json — optional; only present if the user supplied their own OAuth client credentials.

No other files are written by gsuite-mcp. Email content, attachments, and calendar events are streamed to the user's MCP client as they are fetched and are not persisted to disk by gsuite-mcp, except where the user explicitly invokes a tool that writes to a path they specify (for example, gmail_bulk_export or gmail_download_attachments).

Sharing

gsuite-mcp does not share user data with any third party. The only network destinations contacted by gsuite-mcp are Google's own API endpoints (accounts.google.com, oauth2.googleapis.com, gmail.googleapis.com, www.googleapis.com), reached using the user's own access token.

Revoking access

The user may revoke gsuite-mcp's access at any time from https://myaccount.google.com/permissions. Deleting ~/.config/gmail-mcp/token.json removes the locally cached credentials.

Children

gsuite-mcp is a developer tool and is not directed at children under 13.
